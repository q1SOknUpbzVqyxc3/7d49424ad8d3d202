# Spec: переносимая айдентика

Status: ready-for-agent

Дата: 2026-08-22

## Задача

Сделать смену названия команды операцией одной команды, а не ручной правкой
122 файлов. В объём входит имя, домен и контакты (почты, Telegram).

## Не входит

- Перерисовка 40 OG-карточек в `assets/og/` и фавиконок в `assets/img/`.
  Это растр с именем внутри; после переименования превью в соцсетях будет
  показывать старое имя, пока картинки не перерисуют отдельной задачей.
- Смена палитры, шрифтов, логотипа-марки (SVG-ромб не содержит имени).
- Переезд на сборку с шаблонами. Обсуждалось, отклонено: противоречит
  ограничению проекта «no build step, no package manager» и по объёму больше,
  чем сама задача.

## Текущее состояние (замерено)

| Что | Вхождений |
|---|---|
| `syndicatebuiltads.com` | 876 |
| `syndicatebuiltads` без TLD (Telegram, почты) | 141 |
| `sba-motion` | 363 |
| `sbaMarka` / `sbaMarkf` | по 242 |
| Файлов с именем бренда | 122 |

Имя в логотипе разорвано разметкой в **121 файле**:

```html
<span class="logo__name">Syndicate<span aria-hidden="true"> </span>Built<span aria-hidden="true"> </span>Ads</span>
```

Замена по строке `Syndicate Built Ads` этот случай не увидит.

`assets/site.webmanifest` содержит `"short_name": "Syndicate"` — подстроку
полного имени.

## Дизайн

### 1. `brand.json` в корне

Единственный источник правды о текущем бренде. Скрипт читает из него старые
значения и переписывает новыми после успешного прогона.

```json
{
  "name": "Syndicate Built Ads",
  "shortName": "Syndicate",
  "tagline": "Performance systems",
  "domain": "syndicatebuiltads.com",
  "emails": { "general": "hello", "careers": "careers" },
  "telegram": "syndicatebuiltads",
  "prefix": "sba"
}
```

### 2. Подготовительный коммит (нормализация)

Без него скрипт даёт неполную замену. Отдельный коммит, визуально не меняющий
ничего:

1. Схлопнуть `.logo__name` в шапке и подвале до одного текстового узла:
   `<span class="logo__name">Syndicate Built Ads</span>`. Спаны с
   `aria-hidden="true"` вокруг пробелов структурные — у ссылки-логотипа свой
   `aria-label`, а `letter-spacing: 0.14em` объявлен на `.logo__name`
   (`assets/css/main.css:595`), не на спанах. Удаление ни на вид, ни на
   доступность не влияет.
2. Оставить `sbaMarka` / `sbaMarkf` как есть по написанию, но зафиксировать их
   в спеке как производные от `prefix` — скрипт меняет их вместе с ним.
3. То же для ключей `sba-motion` и `sba-lang` (инлайн-скрипт в `<head>` каждой
   страницы, `assets/js/main.js:153`, корневой `index.html`).

Проверка после нормализации: `grep -c 'Syndicate Built Ads'` должен вырасти
ровно на 242 (шапка + подвал на 121 странице).

### 3. `tools/rebrand.mjs`

Один файл, Node 24 (в системе `v24.19.0`), ноль зависимостей, `package.json`
не создаём.

```bash
node tools/rebrand.mjs --name "Новое Имя" --domain newdomain.com \
  --telegram newhandle --prefix nn [--short "Новое"] [--tagline "..."] [--dry]
```

Поведение:

- Отказывается работать при грязном рабочем дереве, чтобы `git diff` был
  полноценным ревью переименования. `--dry` печатает отчёт без записи и это
  ограничение не применяет.
- Обязательны `--name`, `--domain`, `--telegram`, `--prefix`. Необязательны:
  `--short` (по умолчанию первое слово `--name`), `--tagline` (по умолчанию
  остаётся прежним), `--dry`.

**Область обхода — явный список, не рекурсивный обход корня:**

- `index.html`, `404.html`, `robots.txt`, `sitemap.xml`, `_headers`
- `assets/**/*.{css,js,webmanifest}`
- `{ru,en,uk,es,cs}/**/*.{html,xml}`

Не трогаем `.git/`, `.claude/`, `.scratch/`, `docs/`, `CLAUDE.md`, бинарники
в `assets/img/` и `assets/og/`.

**Замена — один проход, не последовательные.** Собираем одно регулярное
выражение из всех шаблонов, отсортированных по убыванию длины, и заменяем
через таблицу соответствий:

```js
const re = new RegExp(patterns.map(escapeRe).join("|"), "g");
text.replace(re, m => map[m]);
```

Так каждая позиция в файле совпадает ровно один раз, и каскад невозможен.
Последовательные проходы здесь ломаются: `syndicatebuiltads` — префикс
`syndicatebuiltads.com`, и замена короткого шаблона первой увела бы 876 ссылок
на несуществующий домен. По той же причине `Syndicate Built Ads` должно
матчиться раньше `Syndicate` (`short_name` в манифесте).

Таблица шаблонов, порядок задаётся сортировкой по длине:

| Шаблон | Становится |
|---|---|
| `hello@syndicatebuiltads.com` | `{emails.general}@{domain}` |
| `careers@syndicatebuiltads.com` | `{emails.careers}@{domain}` |
| `https://t.me/syndicatebuiltads` | `https://t.me/{telegram}` |
| `syndicatebuiltads.com` | `{domain}` |
| `syndicatebuiltads` | `{telegram}` |
| `Syndicate Built Ads` | `{name}` |
| `Syndicate` | `{shortName}` |
| `sbaMarka` / `sbaMarkf` | `{prefix}Marka` / `{prefix}Markf` |
| `sba-motion` / `sba-lang` | `{prefix}-motion` / `{prefix}-lang` |

- `sitemap.xml` (110 КБ) обрабатывается тем же проходом — там только домен.
- В конце скрипт перезаписывает `brand.json` новыми значениями.

## Проверка

1. `node tools/rebrand.mjs ... --dry` печатает число замен по каждому шаблону;
   сумма по домену должна быть 876 + 141, по имени — 242 + прочие вхождения.
2. После прогона `grep -ri "syndicate"` по области обхода не находит ничего.
   Область обхода задаётся явно — сами спеки в `.scratch/` и `docs/` содержат
   старое имя как исторический контекст, и это ожидаемо:

   ```bash
   grep -ri "syndicate" index.html 404.html robots.txt sitemap.xml _headers assets ru en uk es cs
   ```
3. `git diff --stat` — затронуто 122 файла, ни один не потерял строк.
4. Открыть `ru/`, `en/` локально: логотип, шапка, подвал, переключатель языка
   и `<title>` показывают новое имя.
5. Повторный прогон с прежними значениями — no-op.

## Риски

- Ошибка в регулярном выражении портит 122 файла разом. Смягчается запретом на
  грязное дерево: откат — `git checkout .`.
- Если новое имя содержит символы регулярного выражения, они должны
  экранироваться на стороне подстановки. Тест на имя со скобками и точкой.
- `prefix` меняет ключ `localStorage`: у существующих посетителей настройка
  motion и выбранный язык сбросятся один раз. Приемлемо, отметить в коммите.

## Требует человека после каждого переименования

Скрипт меняет строки, но не смысл. На `/{locale}/about/`, строка 155, текст
играет на самом слове «синдикат»:

- ru: «Мы работаем как **синдикат**: специалисты действуют одной командой…»
- uk: «Ми працюємо як **синдикат**…»
- en: «We work as a **syndicate**…»
- es: «Trabajamos como un **sindicato**…»
- cs: «Fungujeme jako **syndikát**…»

Это не вхождение бренда — это обычное слово в пяти языках, и скрипт его не
трогает и трогать не должен. Но после смены имени фраза остаётся каламбуром
без предмета. Переписывать вручную, во всех пяти локалях.

Вывод общий: после каждого прогона нужно вычитать тексты на отсылки к
прежнему имени. Строки скрипт закроет, игру слов — нет.

## Замечено попутно, вне объёма

Корневой `index.html` стоит под `robots: index, follow`, тогда как все
страницы локалей — под `noindex, nofollow`. Расхождение уже в репозитории,
этой задачей не трогаем.
